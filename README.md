# Currency Converter

A responsive Currency Converter built with React that fetches live exchange rates using a public currency API.

## Live Demo

https://react-currency-convertor-woad.vercel.app/

## Features

- Real-time currency conversion
- Live exchange rates
- Currency swap functionality
- Custom React Hook
- Responsive UI
- Clean component-based architecture

## Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Vite
- Currency API

## Concepts Demonstrated

- useState
- useEffect
- Custom Hooks
- API Integration
- Props
- Component Reusability

## Installation

Clone the repository:

```bash
git clone https://github.com/itsRUDDRA/react-currency-convertor.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
